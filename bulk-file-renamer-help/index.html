Bulk File Renamer: Rename Many Files at Once With a Pattern

What is it?

The Bulk File Renamer turns names like IMG_20261001_0931.JPG into goa-trip-01.jpg for a whole folder at once. Build new names from a pattern with numbers, the file date, today’s date and the old name; find and replace text, with regular expressions if you like; change letter case and spaces; then preview every new name and download the renamed copies as one ZIP file.

Who is it for?

Photographers and families sorting trip photos, office staff organising scanned documents, bloggers preparing SEO-friendly image names, and online sellers naming product images.

How to use it

  1. Tap Choose files to rename (any type, as many as you like).
  2. Type the New name pattern. Tap a token to add it: {name} old name, {n} number, {date} file date, {today} today, {ext} extension.
  3. Set Start number and Number digits, optional Find and Replace with, Letter case, Spaces and Extension.
  4. Check the preview, then press Download renamed files (ZIP). Clear files starts again.

Worked example

Choose three photos, type the pattern goa-trip-{n}, set Number digits to 01, 02…, Letter case lower case, Spaces → -, Extension .jpg (lower). The preview shows goa-trip-01.jpg, goa-trip-02.jpg and goa-trip-03.jpg. {date} uses each file’s last-modified date, usually when a photo was taken or copied.

Are my files uploaded?

No. The file is opened and processed inside your browser, on your own phone or computer. The first time, the tool downloads a free helper program it needs (from a public download server); your files themselves are never sent to us or anyone else.

Errors and how to fix them

  • The find pattern is not a valid regular expression: …: untick the regular-expression option for plain text, or escape symbols like . ( ) with a backslash.
  • “Add files to see their new names”: no files are chosen yet.
  • I got a ZIP, not renamed files: websites cannot rename files on your disk. Unzip it; your originals are unchanged.
  • Two files got the same name: a number like (2) is added automatically, so nothing is overwritten.
